# Casse-tête XL

Puzzles de pavage chronométrés de 9 à 12 pièces : 100 formes à débloquer, défi du jour et sprint.

**Jouer :** https://paul-debug5.github.io/casse-tete-xl/

- S'installe comme une appli : sur iPhone, Partager puis « Sur l'écran d'accueil » ; sur Android, menu ⋮ puis « Installer l'application ».
- Fonctionne hors ligne une fois ouvert une première fois.
- La progression est gardée sur l'appareil. Le « code de sauvegarde » du menu permet de la sauvegarder ou de la transférer.
